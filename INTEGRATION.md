# Integration guide

The integration documentation is now organized into:

- [Embedding and local installation](docs/getting-started.md)
- [Public API reference](docs/api.md)
- [Saved schema and answer types](docs/fields-and-layouts.md)
- [Host hooks and extensibility](docs/hooks-and-extensibility.md)

The submission envelope and notification configuration are proposed host conventions, not built-in library endpoints or exported schema properties. The library contains no database, WordPress runtime, SMTP transport, or credentials.
