# Formcraft open-frame identity

Approved direction B: an open canvas with a detached insertion bar. Flat geometry; no enclosing tile.

- Primary: violet #6d4aaf and graphite #26262c, for light backgrounds.
- Mono: graphite, for one-color use on light backgrounds.
- Reverse: white, for dark backgrounds.
- Favicon: uses a lighter violet in dark browser themes.

SVG wordmarks contain outlined lettering, so no font installation is required. Letterforms are based on Arial Bold with adjusted spacing. Keep proportions intact; allow at least one bar-width of clear space around the mark. Use the mark alone below 120px lockup width. Suggested icon sizes: 16, 24, 32px. The 32-unit geometry uses 4-unit strokes and open gaps to survive reduction.

These are local brand assets, not required library UI. Do not add branding to embedded consumer forms. No trademark clearance is implied.
